# Sistema de Gestión de Vehículos

## Descripción
Aplicación en Java que permite administrar una flota de vehículos utilizando herencia, interfaces y colecciones.

## Funcionalidades
- Registrar vehículos (Auto, Camion, Motocicleta)
- Mostrar todos los vehículos
- Buscar vehículo por placa
- Eliminar vehículo
- Calcular costo de mantenimiento por tipo

## Tecnologías usadas
- Java 17
- Programación Orientada a Objetos (POO)
- Herencia
- Interfaces
- Colecciones (ArrayList)

## Conceptos aplicados
- Herencia con extends
- Interfaces con implements
- Polimorfismo
- Encapsulación
- ArrayList para gestionar objetos
- Validaciones de datos

## Cómo ejecutar
1. Clonar el repositorio
2. Abrir en Eclipse
3. Ejecutar Main.java
